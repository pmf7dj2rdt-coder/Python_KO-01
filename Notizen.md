### Tools
#### Gitignore
Mit dem File ***.gitignore*** könen Folders oder einzelne Files ausgeblendet werden. 

#### Darstellung von Codes

#### Ordner hinzufügen
mit dem code ***git status*** sieht man im Terminal (von Visual Studio Code) welche Ordner schon verknüpft sind und welche noch nicht. Wenn es Rot ist muss man (Bsp .gitignore): ***add .gitignore***

#### Anzeigen der Git Commit Historie
Code ***git commit -m "Commit"*** eingeben
Mit ***git push*** kann man es anzeigen lassen.
